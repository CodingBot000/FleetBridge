# Phase 1 기능 계약

## 목표와 범위
UIKit 차량 목록의 모의 차량 10대에서 Flutter 차량 상세로 이동하고 네이티브로 돌아온다. 실제 차량 제어, 서버, 지도, 인증은 범위 밖이다.

## 현재 상태
Xcode 26.6, UIKit과 Storyboard 기반 앱이며 앱·단위 테스트·UI 테스트 타깃이 있다. 초기 iOS 26.5 Simulator 빌드는 성공했다. Flutter SDK는 현재 PATH에서 찾지 못했다. 기존 배포 대상은 iOS 26.5다.

## 설계 및 계약
- 차량 식별자는 안정적인 문자열이며 Native 목록이 차량 데이터의 원본이다. Flutter는 선택된 차량의 데이터를 채널로 요청한다.
- 상세 진입과 닫기는 명시적인 메시지로 처리한다. 엔진의 소유자와 재사용 및 종료 시점을 구현과 함께 문서화한다.
- 잘못된 식별자, 누락 데이터와 통신 실패는 복구 가능한 오류로 표시하며 로딩 상태를 제공한다.
- Flutter 상세 상태는 Riverpod으로 관리한다. 공식 Add-to-App Swift Package Manager 통합을 우선한다.
- 최소 iOS 18.0을 후보로 호환성 확인 후 결정한다. 검증 전까지 변경하지 않는다.

## 검증 기준
- 모의 차량 10개 표시와 서로 다른 차량 연속 선택, 반복 진입 및 복귀를 검증한다.
- 잘못된 ID, 데이터 누락, 오류 및 로딩을 단위·위젯 테스트로 확인한다.
- iOS Simulator 빌드와 테스트, Flutter 테스트 및 양방향 내비게이션을 실행한다.
- 구현하지 않거나 실행하지 못한 항목은 완료로 기록하지 않는다.
